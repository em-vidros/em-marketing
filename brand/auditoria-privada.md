## 8. Método — para você poder contestar os números

Os dados de post vieram do endpoint interno `/api/v1/feed/user/emvidros/username/` com o header `x-ig-app-id`, chamado de dentro de uma sessão logada no navegador, paginando com `next_max_id`. É o mesmo dado que a interface web consome, então bate com o que aparece na tela.

As medições do logotipo saíram do PNG oficial reamostrado para 1600 px de largura, com decodificação manual do PNG em Python e segmentação das letras por colunas vazias. Cap height medida = 167 px; larguras por letra: V 171 · I 39 · D 161 · R 145 · O 178 · S 139.

A comparação tipográfica usou `measureText` com `actualBoundingBox` no canvas, normalizando cada glifo pela altura do `H`. A medida é invariante a tracking, que é o que permite comparar formas de letra sem saber o espacejamento do logotipo.

**Limitação conhecida:** a medida de espessura de haste (a letra `I`) deu 0,2335 no logotipo contra 0,3983 no Poppins 600 — bem fora da faixa das outras cinco letras. Provavelmente `actualBoundingBox` inclui side bearing para o `I` em alguns motores, o que inflaria o valor das candidatas. Por isso o erro reportado no brandbook exclui o `I`. **Não use essa medida para decidir entre Poppins 600 e 700** — essa escolha fica visual, e está na lista de pendências.
